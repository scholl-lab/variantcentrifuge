21@dataclass 

22class TestResult: 

23 """ 

24 Result from a single association test on a single gene. 

25 

26 Fields 

27 ------ 

28 gene : str 

29 Gene symbol tested. 

30 test_name : str 

31 Short test identifier (e.g. "fisher", "burden", "skat"). 

32 p_value : float | None 

33 Raw (uncorrected) p-value. None when test is skipped (e.g. zero 

34 qualifying variants) — None is NOT the same as 1.0 (failure vs skip). 

35 corrected_p_value : float | None 

36 Multiple-testing-corrected p-value. Populated by AssociationEngine 

37 after all genes are tested. None until correction is applied. 

38 effect_size : float | None 

39 Primary effect size estimate. For Fisher: odds ratio. For regression 

40 tests (Phase 19+): beta coefficient. 

41 ci_lower : float | None 

42 Lower bound of the confidence interval for effect_size. 

43 ci_upper : float | None 

44 Upper bound of the confidence interval for effect_size. 

45 se : float | None 

46 Standard error of the effect size estimate. First-class field for 

47 regression tests (burden, SKAT); None for non-regression tests (Fisher). 

48 n_cases : int 

49 Total number of case samples in the analysis. 

50 n_controls : int 

51 Total number of control samples in the analysis. 

52 n_variants : int 

53 Number of qualifying variants for this gene (after filtering). 

54 extra : dict 

55 Test-specific ancillary data (e.g. contingency table, convergence 

56 flags). Not written to output unless a formatter explicitly accesses it. 

57 """

75@dataclass 

76class AssociationConfig: 

77 """ 

78 Configuration for the association analysis framework. 

79 

80 All fields have defaults that mirror the equivalent keys read from the 

81 cfg dict in gene_burden.py (lines 373-377), so existing workflows can 

82 transition without changing semantics. 

83 

84 Fields 

85 ------ 

86 correction_method : str 

87 Multiple-testing correction method. "fdr" (Benjamini-Hochberg) or 

88 "bonferroni". Default: "fdr". 

89 gene_burden_mode : str 

90 Collapsing strategy for carrier counting. "samples" = unique carrier 

91 samples (CMC/CAST); "alleles" = max allele dosage summed across 

92 samples (preserves diploid constraint). Default: "samples". 

93 confidence_interval_method : str 

94 Method for odds ratio CI computation. Currently "normal_approx" which 

95 tries score -> normal -> logit methods in sequence. Default: 

96 "normal_approx". 

97 confidence_interval_alpha : float 

98 Significance level for CIs. 0.05 gives 95% CIs. Default: 0.05. 

99 continuity_correction : float 

100 Value added to each cell when a zero is present, to stabilise CI 

101 computation. Default: 0.5 (Haldane-Anscombe correction). 

102 """

202class AssociationTest(ABC): 

203 """ 

204 Abstract base class for all association tests. 

205 

206 Subclasses implement a specific statistical test (Fisher, burden regression, 

207 SKAT, etc.) and are registered in AssociationEngine's test registry. Each 

208 subclass is responsible for a single gene at a time; the engine handles 

209 iteration and correction. 

210 

211 Methods 

212 ------- 

213 name : str (property) 

214 Short, lowercase identifier used for test registry lookup and output 

215 column prefixes (e.g. "fisher", "burden", "skat"). 

216 run(gene, contingency_data, config) -> TestResult 

217 Execute the test for one gene and return a TestResult. 

218 check_dependencies() -> None 

219 Raise ImportError if required optional libraries are missing. The 

220 default implementation is a no-op; subclasses override as needed. 

221 """ 

222

244 - control_count : int, total control samples 

245 - proband_carrier_count : int, case carrier samples 

246 - control_carrier_count : int, control carrier samples 

247 - proband_allele_count : int, total alt alleles in cases
